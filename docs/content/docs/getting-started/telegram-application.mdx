---
title: Custom Telegram application
description: Override Teldrive's built-in public Telegram app credentials.
---

Most installations should use the built-in credentials. Teldrive defaults to Telegram Desktop's public application (`app-id` `2496`), so a stock deployment needs no `api_id` or `api_hash` at all. Configure your own only if you want the credentials to be attributable to you, or because your account's traffic must not share a client identifier with every other installation.

## Create credentials

1. Open `https://my.telegram.org`.
2. Sign in.
3. Open **API development tools**.
4. Create an application.
5. Copy `api_id` and `api_hash`.

Keep the API hash private.

## Configure

Environment:

```bash
TELDRIVE_TELEGRAM_APP_ID=12345678
TELDRIVE_TELEGRAM_APP_HASH=0123456789abcdef0123456789abcdef
```

YAML:

```yaml
telegram:
  app-id: 12345678
  app-hash: 0123456789abcdef0123456789abcdef
```

TOML:

```toml
[telegram]
app-id = 12345678
app-hash = "0123456789abcdef0123456789abcdef"
```

For proxy, retry, rate-limit, and filesystem-backend settings, see [Telegram settings](/configuration/telegram).
