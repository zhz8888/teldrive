---
title: 共享
description: 创建公开链接，或向其他 Teldrive 用户授予访问权限。
---

Teldrive 支持**公开链接**和**用户授权**。

## 公开链接

创建公开链接时可以指定：

- `read` 或 `edit` 权限（查看者 / 编辑者）；
- 可选的密码；
- 可选的过期时间（1 小时、1 天、7 天、30 天，或形如 `1d12h` 的自定义时长）。

API 还额外接受一个**最大下载次数**，用于限制该链接在返回 `410` 之前可提供多少次内容下载。Web 界面会显示下载次数，但不提供设置上限的入口——请通过 API 设置。

共享覆盖该条目**以及其中的全部内容**，因此共享一个文件夹就等于共享它整棵子树。

共享 URL 的形式是 `<your Teldrive host>/share/<token>`。**令牌只在创建链接时显示一次** —— Teldrive 只保存其哈希值，无法再次显示。关闭对话框前请先复制；如果弄丢了，请撤销该链接并重新创建一个。

该链接本身就是一种凭证。`edit` 链接会让任何持有它的人——在未设置密码时，甚至无需账号——在该共享范围内创建文件夹、上传文件、重命名条目，并将其移入回收站。只有在你确实需要这些权限时，才签发这样的链接。

对 API 客户端而言，受密码保护的共享使用 `X-Share-Password`。

## 用户授权

如果对方是同一 Teldrive 服务器上的另一个账号，请授予 `read` 或 `edit` 访问权限，而不是创建公开链接。接收方可以在**与我共享**下看到这些授权。

## 撤销

撤销共享/授权只会移除访问权限，不会删除底层文件。

确切的请求/响应结构请参阅 [API 参考](/api/)。
