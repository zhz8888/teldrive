---
title: 存储频道
description: 管理用于存放 Teldrive 文件分片的 Telegram 频道。
---

Teldrive 将文件数据分片存储在 Telegram 频道中，并在 PostgreSQL 中保存它们的映射关系。

这些是**真实的 Telegram 频道**，归属于你登录 Teldrive 时所用的那个 Telegram 账号。Teldrive 以该账号的身份上传和下载，而 bot 必须是它所服务频道的管理员。**发现并同步**只会列出你的账号能够添加管理员的频道，因此由其他 Telegram 账号创建的频道不会出现。

频道名称仅供参考：最终标题可能由 Telegram 决定。

## 自动创建频道

```yaml
telegram:
  auto-channel-create: true
  channel-name-prefix: teldrive
  channel-part-limit: 500000
```

当活跃频道中的分片数达到配置的分片上限时，Teldrive 会新建另一个频道。

只有在启用 `auto-channel-create` 时才会发生频道轮转。关闭后，需要超出活跃频道容量的上传——或者没有选中任何频道的上传——不会新建频道，而是直接**失败**，上传开始以 `409 conflict` 报错。除非你自己管理频道并盯住分片上限，否则请保持它开启。

## 界面

打开**设置 → Telegram 存储 → 频道**，可以：

- 创建频道；
- 发现/同步频道；
- 选择活跃频道；
- 在先选定另一个活跃频道之后，删除未使用的频道。

删除受两条规则限制：仍被引用的文件分片或上传分片所在的频道无法删除；并且**当前选中的频道完全无法删除** —— 请先选择另一个活跃频道，即使当前选中的那个是空的也一样。

切换活跃频道只影响新的分片；已有文件仍保持映射到其原有频道。

`channel-part-limit` 统计的是单个频道中存储的 Telegram 消息数，而不是逻辑文件数——一个文件分片占用一条消息。

Bot 通过后台作业添加到存储频道。参见 [Telegram bot](/using/bots)。
