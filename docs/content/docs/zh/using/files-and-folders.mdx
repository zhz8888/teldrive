---
title: 文件与文件夹
description: 在 Teldrive Web 界面中管理文件和文件夹。
---

**文件**页面支持列表/网格视图、分栏视图、多选、上传、后台上传、复制/移动、创建副本、重命名、共享与取消共享、下载、搜索与排序，以及回收站。

## 选择

单击即可选中。要打开文件夹，请显式打开或双击文件夹，这样选中操作就不会触发挥跳转。

批量操作支持复制、移动和移入回收站。重命名/共享属于单条目操作。

## 查找文件

**搜索文件**按名称匹配（默认按子字符串匹配，也可按需使用正则表达式），并可按类别收窄范围——压缩包、音频、文档、图片、视频、其他——还可按名称、更新时间、大小或 ID 升序或降序排序。筛选条件在页面跳转后依然保留，因此搜索结果的行为就像一个虚拟文件夹，你可以向其中移动或复制内容。

## 复制、移动、重命名与创建副本

你可以使用选中项操作栏，或剪贴板风格的复制/剪切/粘贴控件。**创建副本**是一键在原位复制，是为文件创建版本的最快方式。重命名只修改目录元数据，文件数据不会重新上传。

## 下载

下载选中的文件，或复制带认证信息的下载链接。大文件支持 HTTP range 请求，可用于拖动定位和流式传输。

## 回收站

删除操作会将条目移入**回收站**，你可以在其中**还原**它们或**永久删除**。**清空回收站**会一次性清空你账户下的整个回收站。

永久删除无法撤销。随后清理会在后台异步进行——对应的 Telegram 消息由维护作业回收，因此从回收站移除并非即时完成。
