## 环境要求

- 具备持久化存储的 PostgreSQL 18；`database.url` 中的角色必须能够在 `public` schema 中创建 `pgcrypto` 和 `pg_trgm` 扩展
- Telegram 账号，以及可访问 Telegram 的出站网络
- `security.signing-key` —— 至少 32 个字符
- `security.data-key` —— 恰好 32 字节的 Base64 编码

所有必填项及其设置方式请参阅[配置总览](/configuration/overview)。

对于面向公网的部署，请使用 HTTPS，并确保 PostgreSQL 不暴露在公网。
