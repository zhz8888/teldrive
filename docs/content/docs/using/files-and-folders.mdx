title: Files and folders

The **Files** page supports list/grid views, split view, multi-selection, uploads, background uploads, copy/move, duplicate, rename, sharing and un-sharing, downloads, search and sort, and Trash.

## Selection

Single-click selects. Open folders explicitly or by double-clicking so selection does not trigger navigation.

Bulk actions support copy, move, and trash. Rename/share are single-item actions.

## Find files

**Search files** matches names (substring by default, regular expressions on request) and can be narrowed to a category — archive, audio, document, image, video, other — and sorted by name, updated time, size, or ID in either direction. Filters survive navigation, so a search behaves like a virtual folder you can move and copy into.

## Copy, move, rename, duplicate

Use the selection action bar or clipboard-style copy/cut/paste controls. **Duplicate** is a one-click copy in place and is the fastest way to version a file. Renaming changes catalog metadata; file payloads are not re-uploaded.

## Download

Download selected files or copy authenticated download links. Large files support HTTP range requests for seeking/streaming.

## Trash

Delete moves items to **Trash**, where you can **Restore** them or **Delete forever**. **Clean trash** empties the whole Trash for your account at once.

Deleting forever cannot be undone. Cleanup then runs asynchronously in the background — the Telegram messages are reclaimed by a maintenance job, so removal from Trash is not instantaneous.
