## Requirements

- Go 1.26
- Bun
- Just
- Git
- `sqlc` **exactly v1.31.1** — `just generate-db` and therefore `just check` refuse any other version
- Playwright browsers — `bunx playwright install chromium`, needed by `just ui-check` and `just check`
- PostgreSQL 18 to run the server
- Docker or Podman for `just image`, integration tests, and race tests

Or skip all of it — the Nix flake provides the full toolchain:

```bash
nix develop
```

## Build

```bash
git clone https://github.com/zhz8888/teldrive.git
cd teldrive
just install-tools
just build
./bin/teldrive version
```

`just build` generates the UI API client, builds the Vite/React UI, and embeds it into the Go binary.

## Development

Teldrive refuses to start without configuration. Create a root `.env` first (it is git-ignored) or a `config.toml`:

```bash
TELDRIVE_DATABASE_URL=postgres://postgres:postgres@127.0.0.1:5432/teldrive?sslmode=disable
TELDRIVE_SECURITY_SIGNING_KEY=<at least 32 characters>
TELDRIVE_SECURITY_DATA_KEY=<base64 of exactly 32 bytes>
```

Use the **.env** output of the [Quick start generator](/getting-started/quick-start) to produce compatible values. The `justfile` loads `.env` for every recipe.

```bash
just dev
```

This runs the backend on `http://127.0.0.1:8080` and the Vite dev server on `http://127.0.0.1:5173`, which proxies `/api` to the backend. Open the Vite URL during development; the backend's own UI at `:8080` serves the previously built bundle. Do not commit production secrets.

## Validate changes

```bash
just test-unit
just ui-check
just check
```

`just check` runs generation, linting, builds, tests, and coverage checks.

## Generated code

TypeSpec under `typespec/` owns the HTTP contract. After API changes:

```bash
just generate-api
just generate-ui
```

or:

```bash
just generate
```

After SQL/query changes:

```bash
just generate-db
```

Use repository targets instead of editing generated OpenAPI/API/SQLC output directly.

## Container image

```bash
just image
```

This builds the root `Dockerfile` with the container runtime that answers (Docker or Podman) and tags the result **locally** as `teldrive-backend:dev` — it is not pushed to `ghcr.io`. The image is a multi-stage build (Bun/Vite UI → `golang:1.26-alpine` → `gcr.io/distroless/static-debian12:nonroot`) producing the same static binary the release archives ship.

## Documentation site

```bash
just docs-dev
just docs-build
```

`docs/content/docs/{en,zh}/configuration/reference.mdx` is generated by `just docs-generate`; do not hand-edit it.
