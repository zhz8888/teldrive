---
title: Sharing
description: Create public links or grant access to another Teldrive user.
---

Teldrive supports **public links** and **user grants**.

## Public links

A public link can be created with:

- `read` or `edit` permission (Viewer / Editor);
- an optional password;
- an optional expiration (1 hour, 1 day, 7 days, 30 days, or a custom duration such as `1d12h`).

The API additionally accepts a **maximum download count**, which caps how many content downloads the link serves before it returns `410`. The web UI displays the download count but does not offer to set the cap — set it through the API.

A share covers the item **and everything inside it**, so sharing a folder shares its whole subtree.

The share URL is `<your Teldrive host>/share/<token>`. **The token is shown once, when the link is created** — Teldrive stores only a hash and cannot show it again. Copy it before closing the dialog; if you lose it, revoke the link and create a new one.

The link is a credential. An `edit` link lets whoever holds it — with no account, if there is no password — create folders, upload files, rename items, and move them to Trash inside the share. Only issue one when that is what you want.

Password-protected shares use `X-Share-Password` for API clients.

## User grants

For another account on the same Teldrive server, grant `read` or `edit` access instead of creating a public link. Recipients see grants under **Shared with me**.

## Revoke

Revoking a share/grant removes access without deleting the underlying file.

For exact request/response schemas, use the [API Reference](/api/).
