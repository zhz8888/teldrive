## This documentation describes a fork

Teldrive is developed upstream at [tgdrive/teldrive](https://github.com/tgdrive/teldrive) by
[divyam234](https://github.com/divyam234) and the project's contributors. This site documents the
fork maintained at [zhz8888/teldrive](https://github.com/zhz8888/teldrive), and that fork is where
the container images (`ghcr.io/zhz8888/teldrive`), the release archives, the issue tracker and the
pull requests live.
